# REST API Project

A beginner-friendly REST API built with **Node.js** and **Express.js** to understand REST APIs and CRUD operations.

## 🚀 Features

* Get all users
* Create a new user
* Update a user
* Partially update a user
* Delete a user
* JSON data handling
* Express middleware
* Postman API testing

## 🛠️ Tech Stack

* Node.js
* Express.js
* JavaScript
* JSON
* Postman

## 📌 API Endpoints

| Method | Endpoint         | Description             |
| ------ | ---------------- | ----------------------- |
| GET    | `/api/users`     | Get all users           |
| GET    | `/users`         | Display users as HTML   |
| POST   | `/api/users`     | Create a new user       |
| PUT    | `/api/users/:id` | Update a user           |
| PATCH  | `/api/users/:id` | Partially update a user |
| DELETE | `/api/users/:id` | Delete a user           |

## 💻 Running Locally

1. **Clone the repository:**

```bash
git clone https://github.com/thedevnix/Rest-api-project.git
cd Rest-api-project
```

2. **Install dependencies:**

```bash
npm install
```

3. **Start the server:**

```bash
node index.js
```

4. **Open in browser:**

```text
http://localhost:3000
```

## 🧪 Postman

Use Postman to test all REST API endpoints.

Example:

```text
GET     http://localhost:3000/api/users
POST    http://localhost:3000/api/users
PUT     http://localhost:3000/api/users/1
PATCH   http://localhost:3000/api/users/1
DELETE  http://localhost:3000/api/users/1
```
